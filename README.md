# Running the Admin Panel

To use the Admin Panel for editing rooms and syncing types:

1. **Start the Admin API server:**

   ```sh
   npm run admin
   ```

   This will start the admin backend at http://localhost:3001.

2. **Open the Admin Panel in your app.**
   - The frontend will connect to the backend automatically.
   - If you see errors about not reaching the admin server, make sure `npm run admin` is running.

3. **Syncing Types and Index:**
   - Use the "Sync types & index" button in the Admin Panel after saving a new room.
   - Or, you can POST to `http://localhost:3001/api/sync` manually if needed.

**Troubleshooting:**

- If you get errors about missing dependencies, run:
  ```sh
  npm install
  ```
- If you change room files manually, always sync types/index via the Admin Panel or API.
